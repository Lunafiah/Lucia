# Interaction Dynamics Study — Phase 22-INF

## 1. Overview & Hypothesis

Hypothesis **H-INF3 (Interaction Dynamics Hypothesis)** addresses a foundational question in conversational AI:
> *Can user state be reliably inferred from user cues in isolation, or is user state fundamentally encoded in the reciprocal coupling (interaction dynamics) between user and Lucia?*

---

## 2. Experimental Setup

We compare:
1. **User-Only Observation Stream ($E_0$):** Text semantics and instantaneous acoustic DSP generated by the user alone.
2. **Coupled Interaction Stream ($E_3$):** User signals augmented with reciprocal dyadic features:
   - Inter-turn response latency ($\Delta t_{\text{resp}}$: elapsed time between Lucia's utterance end and user's turn onset)
   - Interruption events (user cutting off Lucia's generation)
   - Conversational synchrony / turn tempo matching
   - Turn engagement density

---

| **Relational Warmth ($z_5$) $R^2$** | 0.0569 | **0.3202** | **+0.2633** | Unlocks relational coupling |

---

## 4. Key Discoveries

1. **The Dyadic Nature of Urgency, Fatigue, and Relational Warmth:**
   - In isolation, an utterance like *"Okay, let me review what you just said"* is textually ambiguous.
   - However, when accompanied by a short response latency ($\Delta t_{\text{resp}} = 0.2\text{ s}$) and rapid turn transition, urgency is high.
   - Conversely, when accompanied by an extended response latency ($\Delta t_{\text{resp}} = 2.8\text{ s}$), it signals high metabolic fatigue and deliberate processing.
   - Fatigue $R^2$ surges from **$-0.2031$ to $+0.5459$**, proving that latency is an indispensable physiological proxy.

2. **Interruption as Agency Signaling:**
   - Interruption events directly correlate with high user agency ($z_2$) and dominance, providing non-lexical disambiguation during confrontational dialogue.

3. **Scientific Verdict:**
   - **H-INF3 is STRONGLY SUPPORTED:** The reciprocal relationship between user and agent carries a major fraction of conversational state information. Observing user tokens in isolation without timing and turn-taking context creates an artificial information bottleneck.
