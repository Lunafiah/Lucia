## Overview

This directory contains research contracts, evaluation specifications, and future test fixtures for **Phase 23: Semantic Formation & Continuous Communication**.

Phase 23 investigates the bridge between continuous multimodal cognitive/relational states and persistent, grounded, compositional, language-independent semantic states that drive continuous communication without making an LLM or natural-language token sequence a necessary cognitive substrate.

## Key Invariants Inherited From Phase 22

1. **Substrate Neutrality:** Relational semantics operates independently of natural-language tokens or SLM prompts.
2. **Inherited Interface:** Phase 23 directly inherits `RelationalConditioningState` (120–180 bytes) as established by Phase 22-SC.
3. **Semantic Continuity Invariant:** $\text{Semantic continuity} \neq \text{open-loop accumulation of latent variables}$. Continuity requires persistent structured state, episodic anchors, provenance, and controlled state updates.
4. **Inherited Candidate:** Candidate C4 (Hybrid Graph + HDC Gestalt) is the starting baseline for extension tests, but is not prematurely assumed to be universally optimal for all recursive open-domain semantics.
