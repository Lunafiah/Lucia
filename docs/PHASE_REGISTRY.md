## 4. Phase Governance & Promotion Matrix

Every phase advances according to defined governance rules:

1. **Research $\neq$ Production**: Passing research benchmarks in `tests/evaluation/` or `evaluation_artifacts/` does **NOT** authorize modifying `src/core/`.
2. **Architecture Decision Gate**: Modifying cognitive pipelines or state representations requires authoring an ADR and receiving user authorization.
3. **Rollback & Feature Flags**: Promoted subsystems must include feature flags (e.g. `enable_affective_recollection`, `enable_relational_consolidation`) ensuring bit-exact rollback to the previous milestone.
4. **Epistemic Invariant**: Any unproven hypothesis remains `UNKNOWN`. Failed hypotheses are archived as negative evidence.
