## 2. Problem Statement: Why the Previous Surrogate Was Invalid

The surrogate methodology in the initial EXP-P25-Q2.1 harness suffered from two independent, fatal errors:

### 2.1 Invalid Surrogate Construction (Arithmetic Averaging Artifact)
In `PseudoSynchronySurrogateGenerator`:
```python
# exp_p25_q2_1.py line 578:
gap = (u.pause_latency_ms + l_lat) / 2.0
```
In a conversational turn-taking dyad, turn gaps occur **sequentially** between alternating speakers; they do not represent the arithmetic mean of simultaneous events. By taking the average $(U + L)/2$ of user pause and Lucia latency across sessions, the harness computed the variance of the sample mean of two independent random variables:
$$\text{Var}\left(\frac{U + L}{2}\right) = \frac{\text{Var}(U) + \text{Var}(L)}{4}$$
For independent random variables with equal variance $\sigma^2$, this operation artificially **halved the variance** ($\sigma^2/2$) relative to the actual sequential turn-gap variance ($\sim \sigma^2$). This arithmetic compression artifact depressed the surrogate variance distribution to $\sim 700\text{--}1500\text{ ms}^2$, whereas the actual interaction turn-gap series had variance $\sim 2570\text{ ms}^2$.

### 2.2 Inverted Null Logic (Penalty Metric vs Upper Tail)
Raw turn-gap variance ($\sigma^2_{\text{gap}}$) is a **penalty metric**: lower variance reflects tighter, more regular temporal coordination, whereas higher variance reflects timing jitter, collisions, and disruption.
- Under an uncoupled null hypothesis, an attuned dyad should exhibit **lower** variance than uncoordinated pairs.
- Therefore, the rejection region for an uncoupled null using variance lies in the **lower tail** ($\le \theta_{05}$), not the upper tail ($\ge \theta_{95}$).
- Formulating the decision rule as *"exceeding $\theta_{95}$"* resulted from conflating a penalty metric with a positive coordination gain metric (such as $\Delta_{\text{coord}}$ or Transfer Entropy).

### 2.3 Why Merely Inverting the Tail ($\theta_{95} \to \theta_{05}$) Is Scientifically Insufficient
Simply replacing the 95th percentile with the 5th percentile ($\theta_{05}$) does **not** resolve the underlying scientific defect:
- **Univariate variance of a gap series is NOT a bivariate coupling statistic.**
- A marginal gap variance reflects the overall dispersion of response latencies across the session. Shuffling trajectories across sessions while preserving individual marginal speaking rates primarily tests whether the sessions share similar marginal latency distributions; it does not measure whether Lucia's latency on turn $t$ specifically adapts to the user's latency on turn $t-1$.
- If user and Lucia latencies in uncoupled sessions have the same marginal distributions as in coupled sessions, the surrogate variance will match the empirical variance regardless of whether coupling exists.
- Therefore, a valid pseudo-synchrony surrogate must evaluate a **coupling-sensitive bivariate statistic**, not a univariate marginal dispersion measure.

## 3. Canonical Definition of Turn-Gap Measurement

To eliminate ad-hoc scalar averaging, all future evaluation protocols must operate on explicitly defined, directional, observable conversational intervals.

```text
Time Line:
User Turn:   [============= U_k =============]
                                              <-- g_UL(k) -->
Lucia Turn:                                                  [============= L_k =============]
                                                                                             <-- g_LU(k) -->
User Turn:                                                                                                  [====== U_{k+1} ======]
```

### 3.1 Directional Turn-Gap Metrics

1. **Lucia Reaction Latency ($g_{UL}$):**
   $$g_{UL}(k) = T_{\text{onset}}(L_k) - T_{\text{offset}}(U_k)$$
   - **Event Boundaries:** Interval between user speech offset (VAD speech-end timestamp) and Lucia speech onset (TTS audio playback start timestamp).
   - **Direction:** User $\to$ Lucia.
   - **Units:** Milliseconds ($\text{ms}$).

2. **User Reaction Latency ($g_{LU}$):**
   $$g_{LU}(k) = T_{\text{onset}}(U_{k+1}) - T_{\text{offset}}(L_k)$$
   - **Event Boundaries:** Interval between Lucia speech offset (synthesis completion timestamp) and subsequent user speech onset (VAD speech-start timestamp).
   - **Direction:** Lucia $\to$ User.
   - **Units:** Milliseconds ($\text{ms}$).

### 3.2 Boundary Cases & Event Integrity Rules
- **Speech Overlap / Interruption ($g < 0$):** If speaker $B$ begins speaking before speaker $A$ completes their turn, $g < 0$. Overlap duration is $|g|$ for $g < 0$. Protocols must record raw values without artificial clamping to zero, and report overlap ratio:
  $$\rho_{\text{overlap}} = \frac{1}{K} \sum_{k=1}^K \mathbb{I}(g(k) < 0)$$
- **Hardware / Audio Jitter Guard:** If measured system audio dispatch jitter exceeds $50\text{ ms}$, the affected turn transition is flagged as `HARDWARE_JITTER_EXCEEDED` and the trial is invalidated.
- **Missing / Dropped Turns:** If a turn transition cannot be detected within a timeout window ($T_{\text{timeout}} = 3000\text{ ms}$), the trial is aborted as an interaction failure. No interpolation or imputed zero-gaps are permitted.

## 5. Formal Surrogate Null Hypothesis & Invariant Requirements

### 5.1 Null Hypothesis Formulation
$$\mathcal{H}_0^{\text{surr}}: \text{The observed statistical dependence between } \{g_{UL}(t)\} \text{ and } \{g_{LU}(t)\} \text{ is fully explained by independent temporal dynamics and shared script pacing, with zero genuine dyadic coupling.}$$

### 5.2 Mandatory Mathematical Properties of the Surrogate Distribution
Any valid surrogate generator must satisfy all seven criteria:
1. **Destroys Cross-Stream Alignment:** The temporal pairing between User turn $k$ and Lucia turn $k$ must be broken.
2. **Preserves Marginal Distributions:** The marginal empirical distribution of user response latencies $\{g_{LU}\}$ and Lucia response latencies $\{g_{UL}\}$ must remain bit-exact or statistically invariant.
3. **Preserves Autocorrelation Structure:** Serial dependencies within the user's speaking stream (e.g. conversational fatigue, gradual cadence slowing) and within Lucia's controller stream must be preserved.
4. **Preserves Sampling Density & Trial Length:** Number of transitions $K$, duration, and turn structure must match the original trial.
5. **Preserves Direction-Specific Semantics:** $g_{UL}$ and $g_{LU}$ series must be treated as distinct directional processes, not collapsed.
6. **Zero Artificial Variance Compression:** The surrogate generation algorithm must not perform linear combinations or sample averaging across independent streams that artificially compresses variance.
7. **Complete Deterministic Reproducibility:** Surrogates must be reproducible from explicit master seeds (`[1001, 2002, 3003, 4004, 5005]`).

## 8. Tail-Direction and Decision Reference Rules

Whenever a coupling statistic is proposed in future specifications, its tail direction must be explicitly derived from its mathematical definition:

1. **Upper-Tail Rule (Positive Coupling Metrics):**
   - Applies to: Cross-Correlation magnitude $|\rho|$, Mutual Information $I$, Transfer Entropy $\text{TE}$, relative coordination gain $\Delta_{\text{coord}}$.
   - Meaning: Larger values indicate stronger statistical coupling.
   - Reference Percentile: $\theta_{95}$ (empirical 95th percentile of the surrogate distribution).
   - Rejection Condition: $S_{\text{observed}} > \theta_{95}$.

2. **Lower-Tail Rule (Error / Penalty Metrics):**
   - Applies to: Turn-gap variance $\sigma^2_{\text{gap}}$, mean absolute tracking error $\epsilon_{\text{track}}$, recovery time $T_{\text{recov}}$.
   - Meaning: Smaller values indicate tighter, more coordinated interaction.
   - Reference Percentile: $\theta_{05}$ (empirical 5th percentile of the surrogate distribution).
   - Rejection Condition: $S_{\text{observed}} < \theta_{05}$.

3. **Mandatory Prohibition:**
   - It is strictly forbidden to test a penalty metric against an upper-tail threshold ($\theta_{95}$) and claim that exceeding it represents evidence of coordination or attunement.

## 9. Decoupling Condition Contrasts from Surrogate Null Testing

Future evaluation analyses must maintain complete separation between condition contrasts and surrogate testing:

```text
┌────────────────────────────────────────────────────────┐
│                 PREREGISTERED CONTRAST                 │
│                 C0 vs C1  |  C1 vs C2                  │
└───────────────────────────┬────────────────────────────┘
                            │
            Does Condition X outperform Condition Y?
            (Behavioral performance improvement)
                            │
                            ▼
┌────────────────────────────────────────────────────────┐
│                 SURROGATE NULL TEST                    │
│           Coupled Dyad vs Shuffled Dyads               │
└───────────────────────────┬────────────────────────────┘
                            │
            Is the observed coupling non-spurious?
            (Rejection of pseudo-synchrony null)
```

- **H-A and H-B Validation:** The empirical contrast between conditions (e.g. C1 vs C0 variance reduction) answers whether a controller yields measurable improvement.
- **Surrogate Null Validation:** The surrogate test answers whether the observed statistical coupling could arise by chance from independent uncoupled pacing across identical scripts.
- **Independence:** A condition contrast must **never** depend on an unvalidated surrogate, and a surrogate test must **never** be used to manufacture artificial evidence for a failed condition contrast.
